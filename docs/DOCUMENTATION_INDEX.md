## Next.js Documentation

**Base URL**: https://nextjs.org/docs

Next.js is a React framework for building full-stack web applications. It auto-configures bundlers/compilers so you can focus on building.

### Two Routers
- **App Router** — Newer router, supports React Server Components and React canary features
- **Pages Router** — Original router, still supported and improved. Uses the React version in `package.json`

### Next.js on Vercel — Feature Details
https://vercel.com/docs/frameworks/nextjs

| Feature | Notes |
|---|---|
| ISR | `fetch(..., { next: { revalidate: N } })` — globally cached + persisted to durable storage on Vercel |
| SSR | Full server-side rendering support |
| Streaming | Streaming responses supported |
| Partial Prerendering (PPR) | Supported |
| Image Optimization | Automatic |
| Font Optimization | Automatic |
| Open Graph Images | Supported |
| Middleware | Runs on Vercel Edge |
| Draft Mode | Supported; secure in Preview Deployments |
| Web Analytics | Built-in |
| Speed Insights (`reportWebVitals`) | Built-in |

### Environments
https://vercel.com/docs/deployments/environments

| Environment | Trigger |
|---|---|
| **Local** | `vercel link` + `vercel env pull` → `.env.local` |
| **Preview** | Push to non-production branch / open PR / run `vercel` |
| **Production** | Push to `main` / run `vercel --prod` |
| **Custom** (Pro/Enterprise) | Manual — staging, QA, etc. |
